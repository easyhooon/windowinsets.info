# Galaxy S24 measurements

The original `main-*.json` files are immutable InsetsProbe 1.3.0 captures from
Samsung RTL Korea/Gumi SM-S921N-KR3 on 2026-09-24.

The same unit was recaptured on 2026-09-28 with InsetsProbe 1.6.0.
`recapture-2026-09-28-rotation/` contains the unchanged six-file sweep:
portrait rotation 0 and landscape rotations 1 and 3 in both navigation modes.
All files report Android 16 / One UI 8.5 build
`BP4A.251205.006.S921NKSSGDZG1`, 480 dpi, font scale 1, full-screen windows and
navigation settings matching the Probe classification.
