# Galaxy S23 Ultra measurements

The original `main-*.json` files are immutable InsetsProbe 1.3.0 captures from
Samsung RTL USA/TX SM-S918U on 2026-09-27.

The same build was recaptured on SM-S918U-US01 on 2026-09-28 with InsetsProbe
1.6.0. `recapture-2026-09-28-rotation/` contains the unchanged six-file sweep:
portrait rotation 0 and landscape rotations 1 and 3 in both navigation modes.
All files report Android 16 / One UI 8.5 build
`BP4A.251205.006.S918USQS8FZG1`, 450 dpi, font scale 1, full-screen windows and
navigation settings matching the Probe classification.
