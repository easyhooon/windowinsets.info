# Galaxy S22 Ultra measurements

The original `main-*.json` files are immutable InsetsProbe 1.3.0 captures from
Samsung RTL Galaxy S22 Ultra SM-S908U on 2026-09-25 (Android 13 / One UI 5.1).
Their DisplayCutout bounds are inconsistent with the 1080 px active window and
their corner radii read 8 px.

Samsung RTL Russia/Moscow SM-S908B-RU1 was captured on 2026-09-28 (UTC) with
InsetsProbe 1.6.0. `recapture-2026-09-28-rotation/` contains the unchanged
six-file sweep: portrait rotation 0 and landscape rotations 1 and 3 in both
navigation modes. All files report Android 15 / One UI 7.0 build
`AP3A.240905.015.A2.S908BXXSIFYI3`, 450 dpi, font scale 1, 1080×2316 px
full-screen windows and navigation settings matching the Probe
classification. The recapture reports a 56×75 px cutout bound centered at
x=540 and 101 px corner radii, which the website now uses.
