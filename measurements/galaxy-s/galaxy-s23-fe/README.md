# Galaxy S23 FE measurements

The original `main-*.json` files are immutable InsetsProbe 1.3.0 captures from
Samsung RTL Galaxy S23 FE SM-S711B (Vietnam/Hanoi) on 2026-09-25.

Samsung RTL Vietnam/Hanoi SM-S711BE-VN3 was captured on 2026-09-28 with
InsetsProbe 1.6.0. `recapture-2026-09-28-rotation/` contains the unchanged
six-file sweep: portrait rotation 0 and landscape rotations 1 and 3 in both
navigation modes. All files report Android 16 / One UI 8.5 build
`BP4A.251205.006.S711BXXSIGZH9`, 450 dpi, font scale 1, full-screen windows
and navigation settings matching the Probe classification.

The gesture files come from the first reservation (14:31 UTC). That session
expired before the 3-button natural-rotation file could be downloaded, so the
3-button files come from a complete second sweep in a second reservation of the
same unit (14:51 UTC). Each navigation mode is therefore one internally
consistent sweep; the partial first-session 3-button files are not registered.
